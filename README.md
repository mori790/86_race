# Tokyo Midnight 86 — Driving Lab

GT86をモチーフにしたブラウザ3Dドライビングゲームの **Phase 1 プロトタイプ**。
仕様書 §50 に従い、都市を作り込む前に、平坦な試験コースで車両・操作・カメラを確認する段階です。

## 起動

Node.js 20.9以上とnpmが必要です。

```sh
npm ci
npm run dev
```

ターミナルに表示されるローカルURLを開き、`START ENGINE` を押してください。
デスクトップのWebGL 2対応ブラウザが対象です。音声は開始ボタンの操作後に有効になります。

```sh
npm test           # 実際のRapierによる物理回帰テスト
npm run typecheck  # TypeScript
npm run build      # 本番ビルド
npm start          # ビルド後の本番サーバー
```

## 操作

| キー | 動作 |
| --- | --- |
| W / ↑ | アクセル |
| S / ↓ | ブレーキ |
| A・D / ←・→ | ステアリング |
| Space | 後輪ハンドブレーキ |
| C | 追従 / コックピット視点 |
| R | スタート地点へリスポーン |
| Q | 停止中に D / R 切替（後退もWで加速） |
| Esc | ポーズ / 再開、操作説明を閉じる |
| M | ミュート |

標準マッピングのゲームパッド: RT=アクセル、LT=ブレーキ、左スティック=操舵、A=ハンドブレーキ、Y=視点切替、Menu=ポーズ。実機ゲームパッドでの検証は未実施です。
ウィンドウのフォーカスを失うと、自動で入力を解除して一時停止します。

## 実装済み

- Next.js App Router / React / TypeScript / React Three Fiber / Drei / Rapier / Zustand。
- 1,250 kgの剛体と4輪の独立レイキャストサスペンション。ばね・圧縮/伸び減衰・接地力・摩擦制限を設定。
- 後輪駆動、前輪操舵、前後ブレーキ配分、ハンドブレーキ、空気抵抗・転がり抵抗。
- トルクカーブ、最終減速比、6速AT、シフト時間、後退ギア。固定60 Hz物理ステップ。
- 速度に応じた操舵角制限と入力平滑化。荷重移動・ロールは剛体と4本のばねから発生。
- 遅延追従カメラ、速度連動FOV、ドライバー視点、加減速時の視点移動、操舵連動ハンドル。
- 約5.25 kmの平坦な閉ループ試験コース、3車線、衝突するガードレール、街灯、路面テクスチャ。
- 手続き生成の車体とホイール、環境反射、ヘッドライト。GLBモデルの代替です。
- RPM連動の合成エンジン音と速度連動ノイズ。録音した実車音の代替です。
- 速度・回転数・ギア・接地輪数・サスペンション・横G・FPSのHUD、ポーズ、リセット。

車体・道路・音声はアプリ内で生成します。フォントのみGoogle Fontsを参照し、接続できない場合はシステムフォントにフォールバックします。

## 検証と限界

`tests/vehicle.test.ts` は、描画を使わず実際のRapierワールドを進め、4輪接地・静荷重でのばね圧縮・50秒で195〜235 km/hへの到達・AT変速・FR駆動・制動・右旋回・後退を確認します。
開発時のテストでは50秒後に215.7 km/h / 6速を確認しました。ブラウザでも始動・加速・視点切替と60 FPS表示を確認しています。全端末の1080p/60 FPS保証や長時間の性能試験は未実施です。

**実車再現の検証は未完了です。** Rapierの摩擦制限付きレイキャストタイヤは実測Pacejkaモデルではありません。スリップは車体の横速度から求める近似で、各輪の独立した回転慣性・実車のトラクション特性は未モデル化です。アンダーステア、パワーオーバーステア、制動時の姿勢の再現度はPhase 2で走行評価・調整します。

未実装の後続フェーズ: 首都高風の都市・高架・トンネル・分岐・橋、実車GLB、実車録音のクロスフェードとトンネル残響、チェックポイント・ラップ計測・ベスト保存、交通車両、セクターストリーミング、ポストプロセス。
コックピットはダッシュボードとハンドルの試作で、実際に後方を映すミラーはありません。

## 調整箇所

- `src/game/physics.ts`: 車重、ホイール位置、ばね/減衰、摩擦、ギア比、トルク、操舵・抵抗。
- `src/game/Vehicle.tsx`: 物理と描画の接続、カメラ、ホイール、リスポーン。
- `src/game/Track.tsx`: 試験コース形状、路面、インスタンシングした設備、衝突境界。
- `src/game/CarModel.tsx`: 手続き生成の仮車体。
- `src/game/input.ts`, `audio.ts`, `store.ts`: 入力、音声、UI状態。
- `src/game/Game.tsx`, `src/app/globals.css`: 画面とHUD。

実装参照: [Rapier vehicle controller](https://rapier.rs/docs/user_guides/javascript/vehicle_controller/)、Next.js同梱の `dist/docs/`。
Rapier 0.19.2は初期化時に非推奨引数の警告を出します。上流のWASM初期化に由来し、今回のテストと実行は成功しています。
